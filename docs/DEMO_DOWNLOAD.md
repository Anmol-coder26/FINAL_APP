Download **SuSagi-Demo.apk** below directly on your Android phone, then open the downloaded file to install **SuSagi Demo**. Android 8.0 or newer is required. Allow installation from your browser when Android asks.

This demo installs separately from your configured SuSagi app. If an older **SuSagi Demo** says the update has a different signature, uninstall only that demo before installing this build. That removes the demo's local data.

Before publishing, the workflow checks the actual APK on an Android 15 emulator: installation, launch, opening transcription, starting recognition, pause/resume, room lobby, call-setup dialog, denied microphone permission, retry, cancel/failed-call cleanup, and reopening the launcher. Unit tests cover PCM observer registration, PCM conversion, separate speakers, transcript updates, and the BHASHINI wire format. These checks do not reproduce every physical phone or verify a real two-device call.

For live transcription, open the call transcription screen, allow microphone access, select the language, and tap **Start live transcription**. An installed Android speech recognition provider is required. For the most reliable cellular-call setup, use **call on another device** and place the listening device next to a speakerphone call. Same-device call audio depends on Android's microphone restrictions. The screen displays provider errors if recognition is unavailable.

For **room calls**, open the voice-call screen and use **Call setup** to enter your reachable call-server URL, BHASHINI Socket.IO URL, inference key, and provisioned ASR service ID. Both phones must use the same Agora app ID as the call server. Create a room on one phone and enter its six-digit code on the other. The screen reports local/caller PCM and speech-session readiness separately. Agora owns the microphone in this mode; its local and per-user remote PCM feed two BHASHINI sessions.

This is a demonstration build with no private Firebase, BHASHINI, Gemini, or backend credentials. BHASHINI settings can be saved in encrypted on-device storage without rebuilding. A working call server and provisioned speech service are still required for real room-call transcription. Firebase alerts and cloud semantic analysis also need the project's real configuration; they have not been verified by the launch checks. This APK is for testing and review, not a claimed production/store-ready release.
